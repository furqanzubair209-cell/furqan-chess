## ✨ Features

| Feature | Details |
| ------- | ------- |
| ♟️ **Two-player chess** | Complete chess gameplay for two players on one device |
| ⏱️ **Time controls** | Multiple chess time controls |
| 📜 **Move history** | Full move list with game review |
| ↩️ **Undo / redo** | Step backward and forward through moves |
| 🔄 **Flip board** | View the board from either side |
| 🎨 **Themes** | Multiple board and app themes |
| 🔊 **Sound effects** | Interactive audio powered by the Web Audio API |
| 📋 **PGN export** | Export finished games in standard PGN format |
| 📊 **Match statistics** | Track results across games |
| 💾 **Saved settings** | Settings and statistics persist via LocalStorage |
| 📱 **Responsive UI** | Modern interface that adapts to phones, tablets, and desktops |

## 🎮 How to Play

1. **Start** a new game.
2. **Select** a time control.
3. **White moves first.**
4. **Select** a piece and make your move.
5. **Use the controls** to undo, redo, flip the board, offer a draw, or resign.
6. **Review** your game history or export the game as PGN when finished.

## 💻 Run Locally

No build step or dependencies are needed.

```bash
git clone https://github.com/furqanzubair209-cell/furqan-chess.git
cd furqan-chess
```

Then open `index.html` in your browser. If your browser blocks scripts when opening the file directly, serve the folder with a simple local server such as the VS Code **Live Server** extension.
