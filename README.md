♟️ Furqan Chess

Furqan Chess is a modern, interactive two-player chess game built using HTML, CSS, and vanilla JavaScript. It provides a smooth chess experience with customizable boards, timers, move history, sound effects, and game statistics.

🌐 Live Demo

Play Furqan Chess online:
"https://furqan-chess-game.netlify.app/" (https://reference-url-citation.invalid/0)

✨ Features

- ♟️ Complete two-player chess gameplay
- ⏱️ Multiple chess time controls
- 📜 Move history and game review
- ↩️ Undo and redo moves
- 🔄 Flip the chessboard
- 🎨 Multiple board and app themes
- 🔊 Interactive sound effects
- 📋 PGN export
- 📊 Match statistics
- 💾 Settings and statistics saved with LocalStorage
- 📱 Responsive and modern user interface

🛠️ Technologies

- HTML5 — Structure
- CSS3 — Styling and responsive design
- JavaScript (ES6+) — Chess logic and functionality
- LocalStorage — Saving settings and statistics
- Web Audio API — Sound effects

🚀 Getting Started

Clone the repository:

git clone https://github.com/YOUR-USERNAME/furqan-chess.git

Open the project folder and launch "index.html" in your browser.

No installation or backend server is required.

🎮 How to Play

1. Start a new game.
2. Select a time control.
3. White moves first.
4. Select a chess piece and make your move.
5. Use the controls to undo, redo, flip the board, offer a draw, or resign.
6. Review your game history or export the game as PGN when finished.
